# Mech-Freunde – Aufgaben und Roadmap

## Mit v1.0 umgesetzt
- [x] Linker und rechter Arm getrennt ausrüstbar; Legacy-Mechs bleiben erhalten.
- [x] Bis zu fünf verschiedene Mechs in eigener Garage.
- [x] Tägliche Missionen für Offline-Sterne.
- [x] Vier auswählbare optische Arenen.
- [x] Frei wählbarer Benutzername plus Spieler-Icons.
- [x] Freiwillige öffentliche Bestenliste.
- [x] Konto-Verknüpfung und Cloud-Spielstand für bestätigte E-Mail/Passwort-Konten.
- [x] Per WhatsApp-Link zum privaten Duell einladen.
- [x] Freundescodes, Anfragen und Ein-Tipp-Einladungen zu Duellen.
- [x] Viererturnier (zwei Halbfinals, Finale) mit privatem Turnierbaum.
- [x] Persönlicher Trainings- und Online-Kampfverlauf.
- [x] Aufgeben und Rückkampf annehmen/ablehnen.

## Für den produktiven Betrieb noch wichtig
- [ ] E-Mail-Provider/SMTP, Redirect-URLs und Manual Identity Linking im Supabase Dashboard kontrollieren.
- [ ] Mit zwei realen Geräten Gastkonto-Konvertierung, E-Mail-Verifizierung, Passwort und Cloud-Wiederherstellung prüfen.
- [ ] Mit vier Geräten komplette Turnierketten und außergewöhnliche Fälle (Disconnect/Timeout) testen.
- [ ] Konto-Wiederherstellung über Passwort-Reset, E-Mail-Wechsel und Familienkonto.
- [ ] Moderation, Meldefunktion und Elternfreigabe für freie Spielernamen; entsprechende Datenschutzinformationen erstellen.
- [ ] Gemeinsame Cloud-Bearbeitungen auf mehreren Geräten mit Konfliktlösung zusammenführen.
- [ ] Zeitlimits/Abbruchregeln für nicht zu Ende gespielte Turniere erweitern.
- [ ] Turnier- und Freundeeinladungen auch als Push-Benachrichtigung (Opt-in, nicht als Pflicht).
- [ ] Rate-Limits/CAPTCHA für eine größere öffentliche Community und Abuse-Analyse.
